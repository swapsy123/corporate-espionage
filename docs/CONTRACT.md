API JSON, all /api data endpoints authenticated. GET /api/session => {user:{email},csrf}; POST /auth/login {email,password} => same; POST /auth/logout (X-CSRF-Token). Other writes X-CSRF-Token from session. Errors {error:string}. GET /api/status => {providerReady,aiReady,refreshing,counts:{competitors,ads,posts,opportunities},ownerEmail}.

Competitor {id,name,notes,paused,archived,lastRefresh,lastError,profiles:[]}. Profile {id,competitorId,platform:'instagram'|'youtube'|'meta',identifier,label,confirmed:boolean}. POST /api/competitors/:id/profiles {platform,identifier,label?,confirmed:false}; PATCH /api/profiles/:id {confirmed:boolean,identifier?,label?}; DELETE /api/profiles/:id. User must review and explicitly confirm profile, never auto confirm guesses. POST /api/refresh {competitorId?} => {jobId}; GET /api/refreshes => recent array {id,competitorId,status,startedAt,finishedAt,error,itemCount}.
GET /api/items?kind=paid|organic&format=...&competitorId=...&q=...&transcript=available|unavailable&minDays=0&sort=signal|recent => array. GET /api/items/:id => item. Throw safe user errors. All pagination, stop on exhaustion; failures throw so parent transaction keeps prior data. Parent handles competitorId/id/timestamps/dedup/ranking.
Intelligence server/intelligence.js exports analyzeItem(item) => analysis sync evidence based heuristics; findPatterns(items) => patterns result shape above; async generateBrief({items,format,audience,offer,objective}) => {sourceEvidence,adaptation,references}; async askLibrary({items,question}) => {answer,citations,insufficient}. AI key env LEVR_AI_API_KEY (OpenAI), model configurable. No invented competitor quotes. Source evidence derived only from stored data.
